## Rules

| Rule | What it flags | Effect on `value_clean` |
|---|---|---|
| `missing` Missing value | No value for the hour (empty in the file or no row at all). | stays missing |
| `negative` Negative value | PM2.5 below 0 ug/m3 is not possible. | set to missing |
| `above_max` Above 2000 ug/m3 | Above the physical limit for ambient air. | set to missing |
| `zero` Zero | Exactly 0 ug/m3. Possible in clean air with whole-number resolution. | flag only, value kept |
| `spike` Isolated spike | A run of at most 2 consecutive hours at or above 300 ug/m3 that is at least 8 times the median of the 2+ valid readings within 4 h before it and the same after it. Smooth episodes (gradual rise or decay) do not qualify. Short real plumes can look like this, so the value is kept unless it is extreme. | flag only, value kept |
| `spike_extreme` Extreme isolated spike | A flagged spike whose readings are all at or above 800 ug/m3, jumping from and back to readings at least 8 times lower within two hours. Such a jump is not supported by any neighbouring hour and is treated as a sensor artefact (the November 2021 episode reaches 978 but rises and falls over many hours). | set to missing |
| `stuck` Stuck sensor | 24 or more identical consecutive hourly readings. | set to missing |
