# Research notebooks

Exploratory analysis, numbered in the order of the research process.

| Notebook | Purpose |
|---|---|
| 01_data_collection | Query sources, record what is available |
| 02_data_quality_assessment | Coverage, gaps, outliers, sensor issues |
| 03_exploratory_data_analysis | Patterns in PM2.5 and weather |
| 04_statistical_analysis | Hypothesis tests and associations |
| 05_feature_engineering | Candidate features and leakage checks |
| 06_baseline_models | Historical mean, persistence, seasonal naive, linear regression |
| 07_model_comparison | Tree-based models and, if justified, LSTM/GRU |
| 08_model_explainability | SHAP and error analysis |

All notebooks are starters. They contain plans only, no results. Logic that is reused moves into `src/aeron/` so notebooks do not become the only copy of the pipeline.
