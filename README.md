# AERON

Air pollution analysis and PM2.5 forecasting for Tashkent, Uzbekistan.

**Status:** early development. Phase 1: checking which air-quality and weather data exist for Tashkent. There is no data, analysis or model yet.

## Data sources under investigation

- [OpenAQ](https://openaq.org/): air-quality measurements
- [Open-Meteo](https://open-meteo.com/): weather data
